# 客户端远程配置中心

后台菜单“系统配置 → 客户端配置”用于维护 FastCatAPP 的远程配置，并将同一版本发布到阿里云 OSS、腾讯云 COS 或 UCloud US3。

## 发布流程

1. 在“配置编辑”中填写面板地址、客户端下载、联系方式与功能开关。
2. 选择输出格式并保存草稿。默认使用兼容旧客户端的 `XOR + Base64`。
3. 在“云存储”中新增目标，填写最小权限的写入凭证和客户端可匿名读取的 HTTPS 地址。
4. 先执行“测试”，确认上传和公开读取均正常。
5. 在“版本与发布”中选择版本和目标。任务会进入 Laravel `default` 队列。
6. 系统先上传 `releases/config-v{版本}.json` 并校验，再替换固定 `config.json`。全部目标成功后，版本才会标记为“已发布”。

发布任务需要现有 Horizon/Supervisor 持续消费 `default` 队列。部署代码后需执行项目的数据库升级命令并重启队列进程。

## 输出格式

- `XOR + Base64`：兼容已有客户端。它只用于混淆，不等同于强加密。
- `签名加密 v2`：在 XOR 内容外增加 Ed25519 签名，可阻止配置被第三方篡改。启用前必须先发布支持该格式的新客户端。
- `明文 JSON`：只建议用于临时调试。

启用签名格式后，把后台显示的 Base64 公钥设置到客户端构建变量：

```text
REMOTE_CONFIG_PUBLIC_KEY
```

设备网关使用相同公钥：

```text
DG_OSS_SIGNING_PUBLIC_KEY
```

私钥由 Catboard 自动生成，使用 Laravel `APP_KEY` 加密后保存在数据库中，不应复制到客户端或 CI。

## 云存储权限

建议为每家云存储创建独立子账号，只授予目标 Bucket 指定前缀的上传/覆盖权限。Bucket 中的配置对象需要允许客户端匿名 HTTPS 读取，但不要授予匿名写入权限。

云存储 AccessKey、SecretKey 和临时令牌使用 Laravel `APP_KEY` 加密保存，接口不会回传明文。更换 `APP_KEY` 前必须先重新保存这些凭证。

## 回滚

历史版本不会直接重新覆盖。点击“创建新草稿”会复制历史内容并分配更高的 `config_version`，确认后再发布。这样客户端的版本仲裁不会把回滚误判为旧配置。
